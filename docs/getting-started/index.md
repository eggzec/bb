# Getting Started

## Prerequisites

- Python 3.12 or later
- A Bitbucket Cloud account with an API token, or access to a Bitbucket Data Center instance

## Pages in this section

- [Installation](installation.md) — install the package and configure environment variables
- [Cloud Quickstart](cloud-quickstart.md) — connect to Bitbucket Cloud and make your first API call
- [Data Center Quickstart](datacenter-quickstart.md) — connect to a self-hosted Bitbucket Data Center instance

## Cloud vs Data Center

Use the **Cloud SDK** (`BBClient`) if you are connecting to `bitbucket.org`. Use the **Data Center SDK** (`BBDCClient`) if you are connecting to a self-hosted Bitbucket Data Center or Bitbucket Server instance at your own domain.
